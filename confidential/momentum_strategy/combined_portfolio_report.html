Strategy Rules

BivarOptimalMomentum (50%)

Monthly, signal day 18, execute day 19:

  1. Check S&P 500 vs MA250. Below → buy GLD
  2. Momentum = 50% × 6-month return + 50% × 12-month return
  3. Filter: mcap >$10B, EBIT > 0, US common stock
  4. Select top 7 by momentum, max 3 per sector
  5. Equal weight (~14.3% each)

BTC Systematic (50%)

Daily, check at close:

  1. RSI(14) > 54
  2. Price > 155-day Moving Average
  3. 20-day Annualised Volatility < 100%
  4. All three true → BUY BTC
  5. Any fails → SELL, go to cash
