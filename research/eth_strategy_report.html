Ethereum Trend StrategySystematic trend-following for Ethereum — beta

A rules-based trend-following system for Ethereum, derived from a parameter grid search on ETH's own history. Invested 42% of the time. 9.2 years of Binance data (Aug 2017–Oct 2026). No look-ahead bias — but see the caveats below before treating this as validated.

Beta status. Unlike the BTC signal, these parameters (RSI>52, MA30, no volatility filter) come from a single in-sample/out-of-sample grid search on ETH alone — 294 configurations tested, only 4 survived both the fit window (2020–2023) and the holdout window (2024–2026) at a comparable bar. This one did. That is weak-to-moderate evidence, not a validated edge. No adversarial audit has been run on this strategy yet.

How These Parameters Were Found

The BTC signal's rule (RSI>54, MA155, vol<100%) applied as-is to ETH underperforms: Sharpe 0.89 vs 1.02 for this version. A 294-configuration grid (RSI threshold 48–60, MA length 30–200, vol filter 0.6–unfiltered) was split into a fit window (2020–2023) and a holdout window (2024–2026). Configurations that ranked in the top 30% of both windows simultaneously — not just one — were kept. Only 4 of 294 qualified; RSI>52 / MA30 / no vol filter had the best holdout Sharpe (1.13) among them on the fit split, and re-estimated on the full history gives the numbers on this page.

Why no volatility filter: every version with the BTC-style vol<100% filter scored lower in both windows. ETH's high-volatility periods, it turns out, are disproportionately where this signal's edge lives — cutting them out removes the best trades along with the worst ones.

Caveats

Single-asset optimization. The grid search was run on ETH only. The same "MA30, no vol filter" shape has not been confirmed on other assets outside this BTC/ETH/SOL set — treat it as an ETH-specific finding until shown otherwise.

Short history for this asset class. 9.2 years, one full market cycle and change. Crypto regimes shift fast.

Deep drawdown. -60% is a real number investors need to be able to sit through, not just read.

Costs. ~16 round trips/yr × 0.12% (6bps each way) = modest drag, included in the backtest, but real-world slippage on exchange execution can run higher.

Cash drag. In cash 58% of the time at 0% yield in this backtest.

No adversarial audit yet. Every other live/beta strategy on this site went through a hostile second-pass review before publishing. This one has not, yet — it is published here for transparency, not as a recommendation.
